# Contributing to SpecKub

Thank you for helping build SpecKub.

1. Open an issue for substantial changes.
2. Branch from `main` and keep pull requests focused.
3. Run `pnpm lint && pnpm typecheck && pnpm test && pnpm build`.
4. Add tests for behavior changes.
5. Never commit API keys, credentials or customer data.

Please be respectful and constructive in issues and code review.
